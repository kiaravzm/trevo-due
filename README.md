# AgencyDocs (working title)

## What is this?
AgencyDocs is a lightweight tool to create professional **proposals and invoices** in PDF format for small service-based agencies.

It focuses on speed, clarity, and professional presentation — without the complexity of full accounting or ERP systems.

---

## Who is this for?
- Small agencies (marketing, development, consulting)
- Service-based businesses that sell high-ticket projects
- Teams that want to standardize proposals and invoices quickly
- Companies that work with clients in USD

---

## What this is NOT
- This is NOT an accounting system
- This does NOT handle payments or transactions
- This does NOT manage taxes or financial reports
- This does NOT include multi-user or role management
- This is NOT a full CRM or ERP

---

## Core features (MVP)
- Create simple proposals
- Create simple invoices
- Export documents as PDF
- USD as default currency
- One clean, professional template

---

## Status
This project is currently under active development as an MVP.
